# Why the disclosure desk has no front end

The reporting operator needs the next unresolved figure, overdue narrative and missing review decision. These are records with relationships. A coding agent can read them, run the workflow and explain the result. The database does not call any model service.

The free base has no collaborative document editor, mobile application, offline synchronisation, drag and drop, XBRL tagging or statutory filing. Its HTML views are read-only snapshots. It suits a trusted operator preparing and reviewing evidence, not people simultaneously editing a published report.

Workiva is a broader reporting platform, and its pricing includes unlimited seats. This base makes no claim of equivalent coverage or lower all-in operating cost. The owner controls the database and the reporting rules. Their installed version can include the screens, connections and team access agreed with Enterprise DNA.

The private operator database uses PGlite locally or a Postgres owner connection. RLS is enabled without public access policies. This is not a multi-tenant service or a permissioned team portal. A database owner can change the rules and history. Back up the records, restrict filesystem access and configure real permissions before adding less-trusted users.
